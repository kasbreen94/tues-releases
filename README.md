# Tues

**Tues** — Android-приложение для домашних рецептов и связанных списков покупок.
Работает офлайн, без аккаунтов и облачной синхронизации: все данные хранятся на телефоне.

## Зачем это нужно

Обычно рецепты и список покупок живут отдельно: продукты из рецепта приходится
переписывать вручную, а количества из нескольких рецептов — складывать в голове.
В Tues рецепт и список связаны: ингредиенты добавляются в нужный список с множителем
порций, одинаковые продукты суммируются, а в строке видно, из какого рецепта она пришла.
Правка рецепта сразу меняет количество в списке, удаление — убирает его вклад.

## Возможности

- **Рецепты:** фото из галереи или камеры, ингредиенты с количеством и единицей, шаги,
  порции, теги, поиск по названию.
- **Списки покупок:** постоянный «Общий» и свои списки, ручные позиции, чекбоксы,
  секции «Не куплено» / «Куплено», вид в одну или две колонки.
- **Добавление из рецепта:** все ингредиенты или выбранные, выбор списка, множитель
  порций; повторное добавление обновляет вклад, а не создаёт дубль.
- **Агрегация:** одинаковые продукты суммируются внутри семьи единиц (масса, объём),
  «шт» и «щепотка» остаются отдельными строками.
- **Словари продуктов и тегов:** системный каталог, «Общий» и свои словари,
  подсказки при вводе, пометки «В словаре» и «Уже в списке».
- **Резервные копии:** экспорт и импорт `.tues` — полная копия или выбранные рецепты,
  списки и словари; фото и связи сохраняются.
- **Обмен:** отправка рецептов, списков и словарей файлом `.tues` через системное
  «Поделиться».
- **Оформление:** светлая и тёмная тема, шрифт Manrope, компактная нижняя навигация.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте `app-release.apk` последнего стабильного релиза.
3. Откройте файл на телефоне и разрешите установку из этого источника
   (Android покажет «Установить неизвестное приложение»).
4. Установите приложение. Нужен Android 8.0 (API 26) или новее.

Первая установка выполняется вручную. Дальше приложение само проверяет обновления:
раз в сутки при запуске и по кнопке «Проверить обновления» в настройках. Обновление
необязательное, показывается окно с версией; установку подтверждает системный
установщик. Тихая установка не используется, данные приложения сохраняются.

## Обновления и каналы

- **Стабильные версии** — этот репозиторий, пакет `tues.app`.
- **Ранний доступ** — отдельный канал для проверки новых сборок; он может опережать
  стабильный релиз.

Приложение проверяет только GitHub Releases. Токен для стабильного канала не нужен:
репозиторий публичный. Для раннего доступа с закрытым репозиторием может понадобиться
токен доступа.

## Приватность и разрешения

- Нет аккаунтов, рекламы, аналитики и Crashlytics.
- Нет облачной синхронизации: данные не покидают устройство, кроме файлов `.tues`,
  которые вы отправляете сами.
- Сеть используется только для проверки обновлений и скачивания APK с GitHub.
- Разрешения: `INTERNET` (проверка обновлений) и `REQUEST_INSTALL_PACKAGES`
  (установка скачанного APK). Доступ к камере и галерее — только через системный
  Photo Picker и внешнюю камеру.

## Статус

Приложение в активной разработке. Стабильные сборки публикуются в **Releases**;
исходный код проекта остаётся закрытым. Первый стабильный релиз появится после
проверки очередной версии в раннем доступе.
