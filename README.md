# Tues

**Рецепты и списки покупок, которые связаны между собой.**

Tues — Android-приложение для рецептов и покупок. Добавьте ингредиенты из рецепта
в список — они появятся там с нужным количеством порций. Одинаковые продукты
объединяются, а не дублируются. Переписывать состав в заметки и держать его
в голове больше не нужно.

## Что умеет

- **Хранить рецепты.** Фото, ингредиенты, шаги, порции и теги — в одной карточке.
- **Создавать список покупок из рецепта.** Все ингредиенты или только нужные,
  с выбором списка и количества порций.
- **Объединять одинаковые продукты.** Позиции из разных рецептов складываются,
  а не появляются в списке дважды.
- **Отмечать купленное.** Покупки можно группировать по спискам и смотреть
  в одну или две колонки.
- **Быстрее вводить продукты.** Подсказки, словари и понятные единицы измерения.
- **Сохранять и делиться.** Резервная копия, импорт и отправка рецептов или списков
  файлом через обычное «Поделиться».

## Как это устроено

Tues работает офлайн. Аккаунт не нужен: рецепты, списки и фото хранятся на телефоне.
Приложение не показывает рекламу и не собирает статистику.

## Установка

1. Откройте раздел **Releases** этого репозитория.
2. Скачайте `app-release.apk` — последнюю стабильную версию.
3. Откройте файл на телефоне и разрешите установку из этого источника.
4. Установите приложение. Нужен Android 8.0 или новее.

Когда выходит новая версия, Tues предложит обновиться. Решение остаётся за вами,
а данные приложения сохраняются.

## Ваши данные

- Без аккаунтов, рекламы, аналитики и облачной синхронизации.
- Рецепты, списки и фото остаются на устройстве.
- Сеть нужна только для проверки обновлений и скачивания новой версии.
- Файлы `.tues`, которыми вы делитесь, уходят только туда, куда вы их отправите.

## О Tues

Tues — небольшое приложение без лишних экранов. Оно помогает держать рецепты
и покупки в одном месте, чтобы не собирать список вручную.

Спасибо, что пользуетесь Tues.
